# 玄幻小说正文写作

1. 读完整细纲和用户提供的任务要求。已有项目协作说明时一并遵循。核对确定的情节、字数、前文承接、设定和文风。关键事实缺失或相互冲突时，请作者补充。
2. 按已确认的情节写作。可以组织段落、对白、感知和衔接。需要改动人物动机、关系、能力、结果或信息揭露顺序时，把具体问题交作者决定。
3. 按需要选用 [场景写法](references/scene-craft.md)。回读时对照细纲，检查叙述是否超出视角人物所知，关键因果能否从场景中看出来，字数与收尾是否符合要求。
4. 正文和核对说明分别交付。已有文件格式和审稿流程时，沿用项目约定。
