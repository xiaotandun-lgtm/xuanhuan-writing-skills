# 策划、专项诊断与审稿

以下写法来自《将夜》《牧神记》的章节笔记和重点场景复核。根据当前章节的问题选用，并检查每条方法的适用条件。

## 章节节奏

- 开篇需要同时立人物和环境时，先给观察者一件非办不可的差事，让人物习惯从相遇中露出来；必要时再用另一人掌握的事实修正初印象。反例是让旁观者当场讲完人物履历，或用视角误差替人物不当行为开脱。
- 高潮先兑现长线压力，再落到当事人此刻最想保住的人或事。旧物、承诺或反复出现的动作适合在新处境中改变一次选择；主要代价已经清楚时，可以用一个看得见的结果收束。反例是回顾伏笔却不改变当下，或突然重置世界来抹掉损失。

## 按问题挑专项

| 专项 | 适用时怎么做 | 反例 |
| --- | --- | --- |
| 世界与伏笔 | 涉及未知规则或推理时，分开可见结果、角色推断、对外说法和读者所知。让一次失败缩小解释范围，或让反对者举出真正的反证。回收时核对前文线索能支持多强的结论。 | 一次异常就推出唯一成因，或决战时才补上胜负所需规则。 |
| 人物与情感 | 关系变化时，让人物各自正在办一件事，用动作、称呼或答话改变下一步。告别或照料可从角色最怕交错的一项职责入手。允许符合人物的闲笔、玩笑和内心话。 | 通过互相介绍背景来代替交锋，或以一句旁白宣布感情升温。 |
| 战斗与力量 | 胜负依赖能力规则时，提前给出必要条件和可见效用，随后兑现边界、资源消耗或代价。高潮可让读者看到某种办法仍然有效，却无法保护另一个具体目标。 | 把从未露面的克制关系塞进决胜一刻，或用升阶抹掉此前承诺的代价。 |
| 思想与主题 | 主题影响行动时，给人物同一约束下各自有理由的选择，用后果表现取舍。允许牺牲者迟疑，也保留由本人作决定的空间。 | 代替别人答应牺牲，事后以旁白补一句大家心意相通。 |

## 审稿清单

- **设定与连续性**：逐处比对冲突的事实、时序、位置、人物状态和资源，注明依据。
- **人物与因果**：核查行动符合当时所知和处境，转折由前置条件支撑，后果在本章或后续有位置。
- **节奏与文笔**：核查关键选择、反馈与情绪能否被感到。规则关系到眼下行动时，可直接解释所需条件。保留有效闲笔、角色声口和有分量的内心话。
- **原创性**：检查是否借用了原作人物、专属设定、标志性措辞或高度可辨识的情节组合。技法应用到本书自己的选择与后果上。
- **返修分级**：区分阻断开写或交稿的问题、可定向修订的问题、可选润色。涉及作者决定时列出待裁定项。
