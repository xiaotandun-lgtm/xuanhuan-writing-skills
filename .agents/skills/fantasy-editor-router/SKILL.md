# 玄幻小说总编辑

1. 先读用户提供的细纲、已有设定和前文。已有项目协作说明时一并遵循。标明已确认的事实、待选方案和缺失信息。影响关键行动的事实冲突由作者裁定。
2. 用 [策划、专项诊断与审稿](references/editorial.md) 中与当前任务相关的条目，检查章初状态、人物所求、触发行动的压力、关键选择、可见后果和章末状态。标明读者和各角色分别知道什么。日常章可以用关系或认知的变化推进。
3. 给出细纲修改建议时，定位原句或节点，说明对阅读的影响，提出最小改动。给正文起草准备任务包时，单列已确认的情节、字数、前文承接、可揭露信息和收尾位置。用户确认细纲并授权写作后，可以把任务包交给 `$scene-prose`。
4. 审稿时逐项核对设定、人物所知、因果与连续性，再评估文笔。问题须能定位。涉及动机、关键选择、结果、规则或揭露顺序的调整回到细纲；细纲成立而场面表现不足时，给出定向返修意见。
