# 原创演示｜从细纲诊断到正文复审

先用总编辑技能检查 [原始细纲](brief.md)，再用正文技能执行 [确认后的写作任务](approved-outline.md)。下文保留了两轮审稿中影响改动的要点。

## 首轮细纲诊断

- **证据不足。** 铜符亮起只说明外河水位高，药船的缆绷紧也只说明船受横流拉扯。保留示警，让芦苇梗穿过闸口的方向提供倒灌证据。
- **选择缺一拍。** 原纲从妹妹伸手直接跳到姐姐割缆。倒灌已起，拉船需要时间，绷紧的缆还卡着闸板。这些条件需要体现在她动手前看到的情形里。
- **代价落空。** 原纲最后捞回整船药，与预先确定的结局冲突。把结果收在同一夜，沈苇亲眼看到被急水卷走的药箱。

## 正文

闸柱上的铜符亮了，青光映在沈苇湿透的袖口。她俯身往闸口看。铜符只报外河水高，水往哪头走，还得看闸底。一截芦苇梗穿过闸口，打了个旋，顺着水渠漂向巷里。

石阶下两户还亮着灯。沈禾伸手去抓缆绳，才一使劲，绳子就在闸槽里咬得更紧。外河的横流扯着药船，船头几次转过来，又被拖偏了。

“姐，娘那只镯子，就换了这一船。”

沈苇拔出刀，刀刃抵上绳子，一时没压下去。水已经漫过最底下那级石阶。就算能把缆从槽里扯出来，也赶不及把船拉进巷了。

“去敲门。两户都叫上来。”

沈禾松了手，提灯跑下石阶。沈苇割断缆绳，扳开闸扣。闸板轰地坐到底，外河的水压上来，把闸板死死顶在槽里。这一夜再抬不动了。她借着闸灯，看见船横出去，船头顶在一块尖石上。

巷里先后响了两回门声。沈禾提着灯回来，两户人都跟着她站上了高阶。沈苇再向闸外望去，水正推着那船往旁边拧。船腰在乱石上一折，药箱接连滚下去，最后一只在石缝里顿了顿，也被急水卷走了。

## 复审

| 核对项 | 正文中的依据 |
| --- | --- |
| 倒灌判断 | 铜符先示警，芦苇梗随后朝巷内漂，读者与沈苇同时看见证据。 |
| 落闸取舍 | 沈禾一拉，绳子咬得更紧。沈苇看见水已漫上石阶，让妹妹去叫人，自己割缆。 |
| 结局与代价 | 两户人上了高阶，药船撞损，最后一只药箱被卷走。场景收在当夜。 |

**实际返修。** 初稿等两户人都登上高阶才写药船撞近处的乱石，中间缺少时间衔接。加上船头先顶住尖石的动作，后面船身折断便有了前因。另将容易读成闸门已落的「从门底钻进来」换成「穿过闸口」，把容易让人误会货况的「空船」改成「药船」。

**验证方式。** 用 Codex CLI 确认仓库目录下的两个技能均可被发现，再把技能正文、对应参考和案例材料传入各次试跑，依次完成细纲诊断、正文起草和审稿。此处正文是经上述复审和人工回读后整理的版本。
